About Me

Developer, consultant, and creator behind CODE UI ANDY—focused on shipping interfaces people actually enjoy using.

I'm Andrew Okeke, also known as CODE UI ANDY - a Mobile and Web Developer, Consultant, and YouTuber based in Lagos, Nigeria.
